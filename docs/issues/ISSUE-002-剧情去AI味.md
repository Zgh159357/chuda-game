# [Content] 剧情文本去「AI味」：重写叙事文案库

> 按主控提示词【四、GitHub 敏捷协同工作流】：先 Issue，确认后再动笔。

## 任务目标

把叙事文本库（`src/config/text.ts` 为主，`src/config/eventFiles.ts` 个别文案为辅）重写一遍，去掉「AI 生成感」，恢复纸质档案应有的克制、具体、土味。**不改任何 key、不改任何数值逻辑、不新增/删除条目**。

## 什么是「AI味」（本库现存的症状，逐条对应实例）

| 症状 | 现库实例（改写前） |
|---|---|
| 1. 对仗金句 / 格言收尾 | `signal_trust_2`「上面数的是人，不是人心。」 |
| 2. 结尾升华点题 | `villager_evt_8`「散场后大伙把场地扫得干干净净。」 |
| 3. 村民说话像宣传语 | `story_xiaowang_3`「本事学在自己身上，谁也拿不走。」 |
| 4. 对称句式煽情 | `mf_model_cadre_text`「没有掌声，只有田埂上的脚印。」 |
| 5. 抽象比喻替代具体细节 | `repair_fail`「有些伤，不是换个绷带就能好的。」 |
| 6. 排比 / 口号腔 | `report_r41_withdraw_pass`「留下的不只是台账，还有一支带不走的队伍。」 |

## 改写原则（验收时逐条对照）

1. **写具体，不写道理**：出现钱数、物件、天气、饭食、人名绰号。能写「讲一天课挣八十块」就不写「把本事留在乡村」。
2. **一句话一件事，一段不超过 3 句**；不点题、不升华、不总结。
3. **村民说人话**：带方言腔、有口头语，可以算小账、可以抱怨；干部/公文才用书面语（eventFiles 正文保持公文文体不动）。
4. **情绪克制**：删感叹号煽情；温情只从细节里漏出来，不直接抒情。
5. **禁**：对仗（不是……是……）、四字格连用、排比、金句、翻译腔、「赋能/抓手/闭环」类套话。
6. **保留**：土味幽默、生活颗粒感、克制的暖意（如老李晒蜂糖、小杨攥钥匙）。

## 验收标准

- [ ] `text.ts` 全部叙事性 value 重写（key 原样）；`eventFiles.ts` 仅动个别 body/desc 的叙事句（公文正文文体保留）；`content.ts` 卡描述可选微调。
- [ ] 全库 0 处「不是……是……」式对仗、0 处格言收尾、0 处排比煽情。
- [ ] 村民台词全部口语化，至少 60% 的村民话语含具体细节（钱数/物件/天气/饭食）。
- [ ] 三段故事线（老李/小杨/小王）保留原情节节点，只换叙述方式。
- [ ] 不新增 key、不删 key、不改 key；tsc 0 错、vitest 25/25、vite build 通过（逻辑零改动，测试不受影响）。
- [ ] grep 确认测试无任何对具体文案字符串的断言（如有则改用 key 断言）。
